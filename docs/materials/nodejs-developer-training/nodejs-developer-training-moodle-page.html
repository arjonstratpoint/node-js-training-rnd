Build, validate, test, and version-control a typed REST API with Express, Prisma, Zod, and Jest — from first principles to an independent capstone

What this program is

A trainer-led cohort for developers who already know basic programming concepts but are new to Node.js. Git, modern JavaScript, TypeScript, and SQL are all taught from first principles — nothing beyond general programming knowledge is assumed. Free tools only, no paid licences, no Docker.

Across four weeks you'll grow one running project — the Task API — from an in-memory v1 in Express to a fully migrated, validated, and tested v4 on Prisma and SQLite. In the final week you build a second, independent API in a new domain: the capstone, with no reference solution to copy from.

What you'll learn

Modern JavaScript, async/await, the Node.js runtime and npm
TypeScript 7 on Node.js
A REST API in Express 5 with middleware and a central error handler
SQL on SQLite, and Prisma 7 with migrations
Zod 4 validation with type inference
Integration tests with Jest 30 and Supertest, run in GitHub Actions
Git and a GitHub pull-request workflow, with Bruno for manual API testing

Suggested pace

About 4 hours a day, 5 days a week, four weeks total. Modules 5, 7, and 9 each pair a long topic list with a large lab (8–12 hours) — budget extra time, and expect these to run long before they run short.

The one rule

Prisma is always version 7, never unversioned. Install prisma@7 and @prisma/client@7, lock both to ^7 in package.json, and use npx prisma@7 for one-off commands. An unversioned install resolves to Prisma 8, whose CLI does not read schema.prisma for this stack.
